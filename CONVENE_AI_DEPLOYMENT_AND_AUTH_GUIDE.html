Convene AI — Operations Manual

Deployment & Google OAuth Setup Guide

Step-by-step instructions for repository owner and Vercel / Supabase administrator

Zero Code Required: The frontend application is already 100% written and integrated with supabase.auth.signInWithOAuth({ provider: 'google' }). The owner only needs to perform this one-time configuration in Google Cloud Console and Supabase.

Part 1: Retrieve OAuth Callback URL from Supabase

  1. Log in to supabase.com/dashboard and select your Convene AI project.
  2. In the left sidebar, click Authentication (user icon) → Providers.
  3. Find Google in the providers list and click to expand it.
  4. Copy the value in the box labeled Callback URL (for OAuth): 
    https://<your-project-id>.supabase.co/auth/v1/callback

Part 2: Create OAuth Credentials in Google Cloud Console

  1. Navigate to console.cloud.google.com and sign in.
  2. Click the top project dropdown → New Project → Name it Convene AI → Click Create.
  3. In the search bar or left menu, open OAuth consent screen:
    • User Type: Select External → Click Create.
    • App Name: Convene AI
    • User support email: Select your email.
    • Developer contact email: Enter your email.
    • Click Save and Continue through Scopes and Test Users.
  4. In the left sidebar, click Credentials:
    • Click + CREATE CREDENTIALS → Select OAuth client ID.
    • Application type: Web application.
    • Name: Convene AI Web Client.
    • Authorized JavaScript origins: Add:
      • https://<your-project-id>.supabase.co
      • https://<your-app-name>.vercel.app
      • http://localhost:3000 and http://localhost:3003
    • Authorized redirect URIs: Paste the exact Supabase callback URL from Part 1:
      • https://<your-project-id>.supabase.co/auth/v1/callback
    • Click Create. Copy your Client ID and Client Secret.

Part 3: Enable Google Provider in Supabase

  1. Return to Supabase Dashboard → Authentication → Providers → Google.
  2. Toggle the switch to ON (Enabled).
  3. Paste the Client ID and Client Secret.
  4. Click Save.

Part 4: Configure Supabase Redirect Whitelist for Vercel

  1. In Supabase, click Authentication → URL Configuration.
  2. Set Site URL to: https://<your-app-name>.vercel.app
  3. Under Redirect URLs, add: https://<your-app-name>.vercel.app/**
  4. Click Save.

Part 5: Vercel Redeployment & Environment Variables

  1. Go to vercel.com → Select your convene-ai project.
  2. Under Settings → Environment Variables, verify:
    • NEXT_PUBLIC_SUPABASE_URL
    • NEXT_PUBLIC_SUPABASE_ANON_KEY
    • SUPABASE_SERVICE_ROLE_KEY
    • GEMINI_API_KEY
  3. Go to the Deployments tab → Click Redeploy on the latest commit.

Part 6: Verified End-to-End User Flow
